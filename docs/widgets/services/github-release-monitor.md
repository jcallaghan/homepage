Learn more about [GitHub Release Monitor](https://github.com/iamspido/github-release-monitor).

This widget reads the `repositories.json` file generated by the GitHub Release Monitor tool to display information about monitored repositories and their release status.

Displays: `["repositories", "new", "uptodate", "status"]`.

```yaml
widget:
  type: github-release-monitor
  configPath: /path/to/github-release-monitor/config
```

For a complete service configuration including the icon:

```yaml
- GitHub Release Monitor:
    icon: github-release-monitor.svg  # or use mdi-github or si-github
    href: https://github.com/iamspido/github-release-monitor
    description: Monitor GitHub releases across repositories
    widget:
      type: github-release-monitor
      configPath: /path/to/github-release-monitor/config
```

## Configuration

The `configPath` should point to the directory containing the `repositories.json` file generated by the GitHub Release Monitor tool.

## Example Configuration

Assuming your GitHub Release Monitor is configured to save its data in `/config/github-release-monitor/`:

```yaml
- GitHub Release Monitor:
    icon: si-github  # or mdi-github or your custom icon
    href: https://github.com/iamspido/github-release-monitor
    widget:
      type: github-release-monitor
      configPath: /config/github-release-monitor
```

## Data Format

The widget expects a `repositories.json` file with the following structure:

```json
[
  {
    "id": "facebook/react",
    "url": "https://github.com/facebook/react",
    "lastSeenReleaseTag": "v19.1.1",
    "isNew": false
  },
  {
    "id": "nodejs/node",
    "url": "https://github.com/nodejs/node", 
    "lastSeenReleaseTag": "v20.1.0",
    "isNew": true
  }
]
```

## Widget Information

- **Repositories**: Total number of monitored repositories
- **New Releases**: Number of repositories with new/unseen releases (`isNew: true`)
- **Up to Date**: Number of repositories without new releases (`isNew: false`)
- **Status**: Overall status showing "Updates Available" or "Up to Date"
